## 3. Historia HU_EU_03_10
**Yo como Organizador, quiero pagar mi reserva con una tarjeta de prueba, para completar el flujo sin que se cobre dinero real.**
Épica: EP-03 Reserva y pago simulado · Sprint 3 · Estado de validación: Con observaciones · Prioridad: Must have

Criterios de aceptación (son la fuente de verdad; los mensajes entre comillas simples son literales y los marcados «Propuesto» no se cambian en silencio):

1. Dónde: pantalla 'Pago'; endpoint de pagos del API.
2. Campos:
2.1 Resumen: número de reserva y monto a pagar en COP.
2.2 Número de tarjeta: obligatorio, numérico de 16 dígitos, teclado numérico.
2.3 Vencimiento (mes y año) y código de seguridad: obligatorios, numéricos.
2.4 Aviso permanente: 'Pago simulado: no se cobrará dinero real.'
2.5 Botón 'Pagar'.
2.6 Tarjetas de prueba visibles para la demo (Propuesto): aprobada 4242 4242 4242 4242 y rechazada 4000 0000 0000 0002.
3. Validación:
3.1 Número vacío o distinto de 16 dígitos: 'Ingrese un número de tarjeta válido.'
3.2 Vencimiento con formato inválido o vencido: 'Ingrese una fecha de vencimiento válida.'
3.3 Código vacío: 'Ingrese el código de seguridad.'
3.4 Cualquier número distinto de las tarjetas de prueba se rechaza (Propuesto).
4. Restricción: no se almacena número de tarjeta, vencimiento ni código, solo el resultado, el monto, una referencia simulada y la fecha; no se mueve dinero ni se llama a una pasarela real; el botón se bloquea mientras se procesa y un segundo pago aprobado sobre una reserva ya pagada se ignora.
5. Éxito: con la tarjeta aprobada el pago queda «aprobado», la reserva «pagada» y se abre la confirmación (HU_EU_03_11).
6. Fallo: con la tarjeta rechazada el pago queda «rechazado», la reserva «pago_rechazado» y aparece 'El pago fue rechazado. Verifique los datos o intente con otra tarjeta.'; el usuario puede reintentar y, si el nuevo intento es aprobado, la reserva pasa a «pagada»; si falla la conexión se aplica HU_EU_01_04; ante un error inesperado: 'No fue posible completar la operación. Intente nuevamente.'

Observación de la historia: RF-PAG-01 (M), RF-PAG-02 (M), RF-PAG-03 (M), RF-PAG-04 (M), RF-PAG-05 (S), RF-PAG-06 (M), RF-PAG-07 (S), RF-PAG-08 (S), RF-GEN-05 (S). RN-09 y RN-17. Tarjetas de prueba Propuesto (PB-07).
