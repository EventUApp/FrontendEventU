## 3. Historia HU_EU_01_04
**Yo como Organizador, quiero que la app me avise cuando está cargando o falla la conexión y que no pierda mis datos al navegar, para continuar sin repetir lo que ya ingresé.**
Épica: EP-04 Experiencia transversal · Sprint 1 · Estado de validación: Con observaciones · Prioridad: Must have

Criterios de aceptación (son la fuente de verdad; los mensajes entre comillas simples son literales y los marcados «Propuesto» no se cambian en silencio):

1. Dónde: todas las pantallas que consumen el API (inicio, resultados, mapa, ficha, paquetes, Mi evento, reserva, pago y confirmación) y la navegación entre ellas.
2. Campos:
2.1 Indicador de carga.
2.2 Mensaje de error de red.
2.3 Botón 'Reintentar'.
2.4 Acción de volver a la pantalla anterior.
3. Validación:
3.1 Durante cada petición se muestra el indicador de carga y se bloquean los botones de envío.
3.2 Si el API tarda por arranque en frío, el indicador se mantiene hasta 60 s (Propuesto) con el texto 'Estamos conectando con el servidor. Esto puede tardar un momento.'
3.3 Sin conexión o tiempo agotado se muestra 'No hay conexión con el servidor. Revise su conexión e intente nuevamente.'
4. Restricción: la app no se cierra ante un error de red; no se muestran códigos, trazas ni datos técnicos; volver a una pantalla anterior no borra el presupuesto, el tipo de evento, los invitados, los filtros, los servicios de 'Mi evento', el paquete elegido ni los datos del cliente ya ingresados.
5. Éxito: al recuperar la conexión, 'Reintentar' repite la petición y muestra el resultado; ir y volver entre pantallas conserva los datos.
6. Fallo: ante un error inesperado del servidor: 'No fue posible completar la operación. Intente nuevamente.' sin datos técnicos.

Observación de la historia: RF-GEN-01 (M), RF-GEN-02 (S), RF-GEN-03 (M), RF-GEN-06 (M). Tarea T2. RNF-FIA-01 y RNF-FIA-02; el tiempo de 60 s es Propuesto (PB-04).
Notas del analista: Dependencia: el cliente del API de esta HU lo usan las demás pantallas, por eso va el Día 1. Riesgo: arranque en frío de 60 s o más. Recorte: eliminar el reintento automático y dejar solo el botón.
